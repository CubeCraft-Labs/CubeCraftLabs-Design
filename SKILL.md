Read the `readme.md` file within this skill, and explore the other available files (tokens/, components/, assets/logos/, guidelines/).

CubeCraftLabs is a distinct sub-brand of CubeCraft Creations. It deliberately does NOT use the Creations blue→purple gradient, Nunito, or rounded corners. If a request is for the storefront / finished-goods side, use the CubeCraft Creations design system instead — not this one.

If creating visual artifacts (slides, mocks, throwaway prototypes), copy assets out and create static HTML files for the user to view. If working on production code, copy assets and read the rules here to design as an expert in this brand.

If the user invokes this skill without other guidance, ask what they want to build, ask a few questions, and act as an expert designer who outputs HTML artifacts or production code as needed.
