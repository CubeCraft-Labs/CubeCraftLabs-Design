A CubeCraftLabs action button: square corners, uppercase mono label, 0.08em tracking.

```jsx
<Button variant="primary">Run build</Button>
<Button variant="secondary">Docs</Button>
<Button variant="ghost">Cancel</Button>
```

Variants: `primary` (gold fill, charcoal text), `secondary` (gold outline), `ghost` (text only, gold on hover). Sizes `sm`/`md`/`lg`. Primary is the single strong CTA per view — don't stack two gold fills side by side.
